# 循练 · 卡片版

独立的三分化训练 Web App。原版仍保留在仓库根目录，卡片版发布在 `/cards/`，两者的个人数据独立存储。

- 原版：https://done1314.github.io/xunlian-fitness/
- 卡片版：https://done1314.github.io/xunlian-fitness/cards/

## 使用

今日训练以叠放卡牌展示 PDF 中的训练图片、组数、次数与动作提示。左滑下一个，右滑上一个，也可用箭头按钮或左右方向键。

顶部休息按钮将当天训练顺延，点击恢复后重新按原计划安排。日期旁打开训练日历，可查看其他日期。训练计划右上角可设置开始日期、推拉蹲顺序、每轮休息及每周固定休息。

计划页按推、拉、蹲分组展示动作图文卡片。右滑删除，8 秒内可撤销；卡片编辑按钮也提供删除入口。底部添加动作，支持选择内置示意图或使用本机图片。自选图片会缩小后保存在当前浏览器，不上传服务器。

我的页面保存昵称、身高、体重、健身目标及目标体重。BMI 自动计算，仅供个人记录。所有资料仅在当前浏览器的本地存储中保存，不会跨设备同步，清除网站数据会清除这些设置。

Safari 中选择“分享 → 添加到主屏幕”可作为独立 Web App 打开。首次联网完整加载后缓存应用和 20 张动作图；离线时可查看与编辑本机计划。

## 设计

以 [Apple 采用 Liquid Glass 指南](https://developer.apple.com/cn/documentation/technologyoverviews/adopting-liquid-glass)为参考，将透明材质集中在导航、日历及休息等操作控件。训练内容采用清晰白色卡片。Web 使用 CSS 背景模糊与高光近似该材质，不调用原生 SwiftUI 材质 API。

支持减少动态效果、高对比度与减少透明度的浏览器媒体查询。自定义手势使用 Pointer Events，按位移和速度判断切换方向，并在边界回弹。

底部导航采用 [gentpan/liquidglass](https://github.com/gentpan/liquidglass) 的 MIT 开源折射引擎，固定在提交 `d5db099ef00828496aa2733e4f35542c05a0b1f8`。代码与许可保存在 `vendor/`，无需在线 CDN。选中区域对导航内容的着色副本应用 SVG 位移；滚动内容经过导航时，只复制与导航相交的卡片，在小范围内进行模糊和折射。字体与控件保持可交互，副本排除在辅助功能树和焦点顺序之外。

此版本在移动尺寸的浏览器中验证了点击、拖动导航、任务切换及滚动时的背景对齐。Safari/WebKit 兼容路径依据上游实现，尚未在实体 iPhone 上验证。原版根目录文件保持不变。

## 开发

无依赖、无构建步骤。用任意静态 HTTP 服务器托管该目录即可。`schedule.js` 与 `plan-data.js` 保留原版训练内容和排期逻辑。`model.js` 提供 BMI 与卡牌切换判断。

验证包括 BMI、手势方向/边界/速度、临时休息顺延的逻辑检查，以及移动尺寸下的浏览器拖动、添加编辑删除撤销、资料保存、训练安排和日历操作。尚未在实体 iPhone 上测试。
